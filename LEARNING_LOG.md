# Learning Log

This file documents what I learned while building From Zero to Mandelbrot.

It is not intended to be a C++ tutorial. It is a record of problems,
misunderstandings, decisions and improvements encountered during the project.

## Stage 0 — Repository setup

I tried GitHub Issues and Milestones for the first time. Milestones were a bit 
confusing at first, but I got the main idea: issues are individual tasks or 
problems, while a milestone groups related issues around a larger goal.

I also accidentally committed the `.idea` directory generated by CLion. I
learned that adding something to `.gitignore` does not remove it if Git is
already tracking it. I had to remove it from Git's tracking separately while
keeping it on my computer.

I got more comfortable with Markdown and learned how to use headings,
lists, links and code blocks to make a document easier to read. I am still
figuring out how to keep documentation useful without overcomplicating it.

## Stage 1 — PPM Image Generator

While building this project, I learned how to generate an image from scratch.
A raster image can be represented as a matrix of pixels, and each pixel has a
value for red, green and blue.

I also got a quick refresher on some basic geometry when I started drawing the
circle and square.

An idea that I had and didn't really work was add the gradient using cosinus.
That idea was good, but I had to refactor too much and the results were not
worthy enough. I will find a solution to integrate this in the next projects. 

I had used Makefiles before, but this was the first time I wrote one for my own
project. I still don't fully understand them, but I now have a rough idea of
how a Makefile is structured and how its rules work.
